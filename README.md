# Esports Platform

A group project esports platform for managing players, teams, scrims, tournaments, matches, rankings, and authentication.

## Structure

- `frontend/` - Client application
- `backend/` - Python API and database models
- `docs/` - Project documentation
- `tests/` - Automated tests

## Setup

```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```
